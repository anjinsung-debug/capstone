# data — 데이터 표준화 / Neo4j 적재 (FR-01, FR-02)

담당: 한승우

| 폴더 | 내용 |
|------|------|
| `raw/` | 한전에서 제공한 22.9kV 배전계통 데이터(가공본). **git에 커밋되지 않음**. 파일 공유는 별도 드라이브로 |
| `samples/` | 개발·테스트용 가상 샘플 계통. 직접 만든 공개 가능한 데이터만 (**한전 데이터 금지**) |
| `mapping/` | 한전 데이터 필드 ↔ CIM 클래스/속성 매핑 테이블 |
| `converter/` | 한전 데이터 → CIM 변환 코드 |
| `validation/` | 변환 결과 검증 스크립트, 예외 케이스 목록 |
| `output/` | CIM 변환 결과 (CIM XML/RDF, CSV 등). 한전 데이터 기반 산출물이므로 **git에 커밋되지 않음** |
| `cypher/` | Neo4j 스키마, 제약조건, 인덱스 정의 (`.cypher`) |
| `loader/` | CIM 데이터를 Neo4j에 적재 (위상·연결·좌표 포함) |
| `tests/` | 테스트 |

**보안**: 한전 제공 데이터와 그 변환 결과는 외부 공개 금지입니다. 저장소가 공개 상태이므로 실제 데이터는 커밋하지 않고, 코드와 매핑 규칙만 올립니다.

**유의사항**: 매핑 난이도가 높으므로 매핑 테이블/검증 스크립트/예외 케이스를 함께 관리한다. 쿼리 성능을 위해 인덱스와 스키마를 최적화한다.
