# data — 데이터 파일 저장소

코드는 두지 않고 데이터 파일만 저장합니다. 데이터 처리 코드는 [`cim/`](../cim/)에 있습니다.

| 폴더 | 내용 | git |
|------|------|-----|
| `raw/` | 한전에서 제공한 22.9kV 배전계통 데이터(가공본) | ❌ 제외 |
| `output/` | CIM 변환 결과 (CIM XML/RDF, CSV 등) | ❌ 제외 |
| `samples/` | 개발·테스트용 가상 샘플 계통. 직접 만든 데이터만 (**한전 데이터 금지**) | ✅ 커밋 |

**보안**: 한전 제공 데이터와 그 변환 결과는 외부 공개 금지입니다. `raw/`, `output/`의 파일은 git에 올라가지 않으며, 팀원 간 공유는 별도 드라이브로 합니다.
