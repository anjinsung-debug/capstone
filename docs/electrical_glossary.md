# 전기·전자 용어표

작성 기준: 2026-10-08. 이 프로젝트는 전자회로보다 22.9kV 배전계통 해석에 초점을 둔다. 아래 설명은 저장소를 이해하기 위한 용어 정리이며, 지원 여부는 현재 구현 기준이다.

## 1. 설비와 계통

| 용어 | 영문·코드 | 뜻 / 프로젝트 맥락 |
|---|---|---|
| 배전계통 | Distribution system | 변전소에서 수용가까지 전력을 공급하는 설비와 연결망 |
| 변전소 | Substation | 전압을 변환하고 전력을 나누어 공급하는 시설. 분석의 기본 단위 |
| 피더 | Feeder | 변전소 출구 차단기에서 시작하는 배전 회선 |
| 전원 | Source | 계통에 전력을 공급하는 부분. 상위 계통을 등가 모델로 표현 |
| 모선 | Busbar / BusbarSection | 여러 회로가 공통으로 연결되는 도체. 원본 모선을 전원 노드로 매핑 |
| 접속점 | Bus / ConnectivityNode | 설비 단자들이 전기적으로 만나는 지점. 물리적 모선과 항상 같지는 않음 |
| 단자 | Terminal | 설비의 전기적 연결 끝부분. 명령창이라는 뜻이 아님 |
| 선로 | Line / ACLineSegment | 전력을 전달하는 전선 구간. 길이·저항·리액턴스를 가짐 |
| 차단기 | Circuit Breaker / CB | 정상 전류와 고장전류를 개폐하는 장치. 현재 출구 차단기는 닫힘으로 모델링 |
| 개폐기 | Switch | 전기 회로를 연결하거나 끊는 장치 |
| 부하개폐기 | LoadBreakSwitch | 부하전류가 흐르는 회로를 개폐하는 장치 |
| 리클로저 | Recloser | 차단 후 자동 재투입 기능을 가진 장치. 코드에서는 일반 switch로 단순화 |
| 단로기 | Disconnector | 설비를 전기적으로 분리하기 위한 장치. 차단기와 역할이 다름 |
| 퓨즈 | Fuse | 과전류로 소자가 녹아 회로를 끊는 보호장치 |
| 부하 | Load / EnergyConsumer | 전력을 소비하는 설비 또는 소비량을 묶은 모델 |
| 수용가 | Consumer / Customer | 전력을 공급받아 사용하는 가정·상점·공장 등의 고객 |
| 분산전원 | Distributed Energy Resources / DER | 배전계통 여러 지점에 연결된 발전원 |
| 태양광 | Photovoltaic / PV | 태양빛으로 발전하는 설비. 원본에 4개 존재 |
| 풍력 | Wind | 바람으로 발전하는 설비. 코드에서 지원하지만 현재 원본에는 없음 |
| 인버터 | Inverter | 직류를 교류로 변환하는 전력변환장치. 현재 고장 모델은 단순화된 발전기 모델 사용 |

## 2. 전기량과 단위

| 용어 | 기호·단위 | 뜻 / 코드 대응 |
|---|---|---|
| 전압 | V, kV | 두 지점 사이의 전위차 |
| 선간전압 | kV | 3상 중 두 상 사이의 전압. 프로젝트 기준 22.9kV |
| 전류 | I, A·kA | 전하가 흐르는 정도 |
| 유효전력 | P, kW·MW | 실제 일·열 등으로 변환되는 전력. `p_kw` |
| 무효전력 | Q, kvar·MVAr | 교류에서 전기장·자기장 형성과 관련해 오가는 전력. `q_kvar` |
| 피상전력 | S, kVA·MVA | 전압·전류로 나타내는 교류 전력의 크기 |
| 역률 | Power factor | 피상전력 중 유효전력의 비율. 이 모델에서 Q=0이면 역률 1 가정 |
| 저항 | R, Ω | 전류 흐름을 방해하고 손실을 발생시키는 성분 |
| 리액턴스 | X, Ω | 인덕턴스·정전용량에 의한 교류 특성 |
| 임피던스 | Z=R+jX, Ω | 저항과 리액턴스를 합친 교류 회로의 특성 |
| 단위 길이당 임피던스 | Ω/km | 선로 1km당 저항·리액턴스. 전체 값은 길이를 곱해 구성 |
| X/R비 | 무차원 | 리액턴스를 저항으로 나눈 값. 기본 가정 10 |
| 정전용량 | Capacitance, F | 전하를 저장하는 성질. 일반 선로 모델에서는 0으로 설정 |
| 허용전류 | A | 허용 조건에서 선로 등이 흘릴 수 있는 전류. 일반 선로 기본 가정 400A |
| 정격전류 | A | 설비의 정격 조건에서 정해진 전류. 원본 차단기는 600A |
| 정격출력 | kW·MW | 설비의 정격 조건에서 정해진 출력. 실제 순간 발전량과는 구분 |
| 단위법 | Per Unit / pu | 실제 값÷기준값. 1.0pu는 기준의 100% |
| 실효값 | RMS | 같은 저항에서 동일한 평균 열 효과를 내는 직류값에 대응하는 교류 크기 |
| 대칭 실효값 | Symmetrical RMS | 비대칭 직류 성분을 제외한 대칭 교류 성분의 실효값 |

1kV=1,000V, 1kA=1,000A, 1MW=1,000kW, 1MVAr=1,000kvar. 코드의 P·Q는 3상 합계다. 기준 22.9kV에서 0.95pu는 21.755kV, 1.05pu는 24.045kV이다.

## 3. 해석과 판정

| 용어 | 영문·코드 | 뜻 / 현재 사용 |
|---|---|---|
| 조류 | Power flow | 계통을 따라 흐르는 유효·무효전력 |
| 조류 계산 | Load flow / Solve | 부하·발전량과 계통 조건으로 전압·전류·전력 흐름 계산 |
| 전압 강하 | Voltage drop | 선로를 지나며 전압이 낮아지는 현상 |
| 전압 프로파일 | Voltage profile | 위치·거리에 따른 전압 분포 |
| 저전압·과전압 | Under/Overvoltage | 판정 범위보다 낮거나 높은 전압. 코드 기준 0.95~1.05pu |
| 선로 부하율 | loading_pct | 전류÷허용전류×100. 시간 평균 사용률이 아님 |
| 과부하 | Overload | 전류가 허용 수준을 초과한 상태. 코드에서는 부하율 100% 초과 |
| 역조류 | Reverse flow | 말단에서 전원 방향으로 전력이 흐르는 현상. 저장된 선 방향만으로 판정하지 않음 |
| 송출 전력 | Feeder power | 변전소에서 피더로 내보내는 전력 |
| 전력손실 | loss_kw | 계통 내부에서 소비되어 부하에 전달되지 못한 전력 |
| 정전·비가압 | energized=False | 전원에서 연결이 끊긴 구간. 코드상 전압 0, 고장전류 None |
| 단락 | Short circuit | 서로 다른 전위의 도체가 낮은 임피던스로 연결되는 고장 |
| 3상 단락 | Three-phase short circuit | 세 상이 단락되는 고장. 현재 반환하는 고장 해석 대상 |
| 고장전류 | fault_current_ka | 고장 시 흐르는 전류. 현재 3상 단락 대칭 실효값 |
| 단락용량 | Short-circuit level, MVA | 단락전류 수준을 전력 단위로 나타낸 값. 전원 기본 가정 300MVA |
| 차단용량 | Breaking capacity | 차단기가 차단할 수 있는 고장 수준. 정격전류 600A와 다르며 현재 비교 기능 없음 |
| 지락 | Ground fault | 전력선이 대지와 연결되는 고장. 현재 해석 범위 밖 |
| 3상 평형 | Balanced three-phase | 세 상 크기가 같고 위상이 120°씩 차이 나는 상태 |
| 정상분 | Positive sequence | 정상 상순서의 평형 3상 성분. R1·X1 사용 |
| 영상분 | Zero sequence | 세 상이 같은 위상을 갖는 성분. 원본 r0·x0는 현재 미사용 |
| 방사형 계통 | Radial network | 전원에서 각 지점으로 연결이 나뭇가지처럼 뻗은 계통 |
| 루프 | Loop | 연결에 폐회로가 있는 구조. 전원 연결 구간에서 발견 시 계산 중단 |
| 무한 모선 | Infinite bus | 전압·주파수가 일정하다고 보는 이상적 전원. 조류 계산 전원을 이에 가깝게 설정 |
| 정전력 모델 | Constant power | 전압 변화에도 P·Q를 일정하게 보는 모델 |
| 정임피던스 모델 | Constant impedance | 임피던스를 일정하게 보며 전압에 따라 전력이 변하는 모델 |
| 과도 리액턴스 | Transient reactance / Xdp | 발전기 과도 상태 전류 특성에 쓰는 리액턴스. 코드 설정 Xdp=1 |
| 수렴 | Convergence | 반복 계산이 허용 오차 안의 해에 도달하는 것 |

## 4. 계통 표현과 데이터

| 용어 | 뜻 / 프로젝트 맥락 |
|---|---|
| 단선도 | 3상 계통을 대표 선과 설비 기호로 간략히 나타낸 그림 |
| 위상 / Topology | 이 코드에서는 설비의 연결 구조. 교류 파형의 위상각과 구분 |
| CIM | Common Information Model. 전력 설비·연결을 공통 형식으로 표현하는 정보 모델 |
| OpenDSS | 배전계통 조류 계산·고장 해석에 사용하는 계산 엔진 |
| 한 시점 계산 | 특정 순간의 부하·발전량을 고정하여 계산. 시간 변화 분석과 구분 |
| 단선도 좌표 | 화면 배치용 x·y. 지리 좌표나 선로 길이가 아님 |
