# OpenDSS 4대 시뮬레이션 데이터 대응표

작성 기준: 2026-10-08 저장소 코드와 `data/korean_distribution_cim.xml`.

이 문서는 현재 프로젝트가 OpenDSS에 전달하고 읽는 값을 정리한다. OpenDSS 전체 기능 명세는 아니다. 원본 XML 자체도 가상 계통 데이터이므로 ‘원본값’은 실측값이라는 뜻이 아니다.

## 1. 계산 구조

계통 입력·연결 검사 → OpenDSS 모델 생성 → `Solve` → 전압·선로 전류·전력 읽기 → 전압/과부하/역조류 판정 → 전원 고장 파라미터 변경 → `Solve mode=faultstudy` → 3상 단락전류 읽기.

앞의 세 항목은 같은 조류 계산 결과를 사용한다. 고장전류는 별도의 고장 해석으로 구한다. 과부하 비율과 역조류 여부는 OpenDSS 결과를 읽은 뒤 Python에서 계산한다.

| 구분 | 의미 | 예시 |
|---|---|---|
| 원본 입력 | 제공된 XML에 있는 값 | 부하 P·Q, 선로 r·x |
| 변환·도출값 | 원본을 환산하거나 연결 구조에서 구한 값 | W→kW, 선로 방향 |
| 가정 입력 | 원본에 없어 보완한 값 | 허용전류 400A, 단락용량 300MVA |
| 모델 설정 | 계산 방법을 지정하는 값 | `phases=3`, `model=1` |
| 판정 기준 | 결과를 평가하는 기준 | 0.95~1.05pu, 부하율 100% |
| 계산 결과 | 입력과 모델로 계산해서 얻은 값 | 전압, 전류, 고장전류 |

## 2. 입력값과 시뮬레이션 대응

‘조류 3종’은 전압 영향·선로 과부하·역조류를 뜻한다. 고장 해석은 같은 계통 모델을 사용하지만 정상 운전 P·Q와 고장전류가 단순 비례하는 것은 아니다.

| 데이터 / 내부 변수 | OpenDSS 전달 위치 | 출처 및 현재 값 | 사용 시뮬레이션 / 역할 |
|---|---|---|---|
| 기준 전압 `BASE_KV` | 전원 `basekv`, 부하·발전기 `kV`, `VoltageBases` | 원본 22,900V 확인 후 코드에서 22.9kV 고정 | 전체: 전압 기준과 설비 모델 전압 |
| 운전 전압 `source_voltage_pu` | 전원 `pu` | 원본 없음 → 기본 1.0pu | 전체: 전원 전압 조건 |
| 연결 `bus_id`, `from_node_id`, `to_node_id` | `bus1`, `bus2` | 원본 Terminal/ConnectivityNode에서 도출 | 전체: 전기적 연결 경로 |
| 설비 종류 `type` | `Circuit`, `Load`, `Generator`, 버스 구성 | 원본 클래스 매핑 | 전체: 전원·소비·발전 모델 구분 |
| 선로 길이 `length_km` | 일반 선로 `length`, `units=km` | 원본 숫자를 km로 해석하는 가정. 단위 확인 필요 | 전체: 구간 임피던스 구성 |
| 정상분 저항 `r_ohm_per_km` | 일반 선로 `R1` | 원본 구간 `ACLineSegment.r`(Ω) ÷ 길이(km) | 전체: 저항 성분 |
| 정상분 리액턴스 `x_ohm_per_km` | 일반 선로 `X1` | 원본 구간 `ACLineSegment.x`(Ω) ÷ 길이(km) | 전체: 리액턴스 성분 |
| 부하 `p_kw` | `Load.kW` | 원본 `EnergyConsumer.p` ÷ 1,000. 8개 합계 12,100kW | 조류 3종의 소비전력 입력. 고장 해석에서도 부하 모델 유지 |
| 부하 `q_kvar` | `Load.kvar` | 원본 `EnergyConsumer.q` ÷ 1,000. 현재 8개 모두 있음 | 조류 3종의 무효전력 입력. 고장 해석에서도 부하 모델 유지 |
| 태양광 `p_kw` | `Generator.kW` | 원본 `nominalP` ÷ 1,000을 실제 출력으로 가정. PV1~4: 1,000/2,000/1,500/500kW | 조류 3종의 발전량. 고장 해석의 발전기 모델 구성에도 사용 |
| 태양광 `q_kvar` | `Generator.kvar` | 원본 없음 → 0kvar, 역률 1 가정 | 조류 3종의 발전원 운전 조건 |
| 일반 선로 허용전류 `rated_current_a` | `Line.normamps`; Python의 부하율 분모 | 원본 없음 → 400A | 과부하 판정 기준. 전류를 400A로 제한하는 값은 아님 |
| 차단기 정격전류 | 차단기 연결선 `normamps`; 부하율 분모 | 원본 `Switch.ratedCurrent=600A` | 차단기 연결선의 부하율. 고장 차단용량과 다름 |
| 개폐 상태 `is_open` | 열린 switch에 닿은 선로 `enabled=no` | 중간 개폐기는 원본에 없음. 출구 차단기는 원본 normalOpen=false이며 코드도 닫힘으로 처리 | 전체: 통전·정전 구간 구분 |
| 연결 종류 `kind` | 일반 `Line` 또는 `Line switch=yes` | 원본 설비/내부 연결에서 도출 | 전체: 물리적 선로와 개폐기 연결 모델 구분 |
| 전원 단락용량 `short_circuit_mva` | 고장 해석 전 `Vsource.MVAsc3` 및 `MVAsc1` | 원본 없음 → 300MVA | 고장전류: 전원 임피던스 구성 |
| 전원 X/R비 `x_r_ratio` | 고장 해석 전 `X1R1` 및 `X0R0` | 원본 없음 → 10 | 고장전류: 전원 저항·리액턴스 비율 |

P·Q는 3상 합계다. 누락된 Q는 일반적으로 0으로 처리한다. 단락용량·X/R비·허용전류는 별도 입력값이 있으면 기본 가정값보다 우선한다. `MVAsc1`, `X0R0`에도 값을 지정하지만, 현재 반환하는 고장 결과는 3상 단락전류뿐이다.

## 3. 모델 설정과 판정 기준

다음 값은 원본 데이터를 계산해서 얻은 결과가 아니라 코드가 미리 설정한 조건이다.

| 항목 | 현재 설정 | 적용 대상 / 의미 |
|---|---|---|
| 조류 계산용 전원 | `STIFF_MVA=1e6`, `MVAsc3=MVAsc1=1,000,000MVA` | 조류 3종: 전원 임피던스를 매우 작게 해 변전소 전압을 거의 일정하게 유지. 고장 해석 전에 실제 입력값 또는 300MVA로 변경 |
| 상 구성 | `phases=3`, 3상 평형 가정 | 전체: 상별 불평형을 별도 분석하지 않음 |
| 계통·시간 범위 | 방사형, 한 시점 | 전체: 루프는 오류 처리, 시계열 분석 없음 |
| 부하·발전기 모델 | `model=1` | 조류 계산의 정전력 모델 설정 |
| 저전압 모델 전환 설정 | `vminpu=0.7` | 부하·발전기의 저전압 모델 전환 기준. 정상 전압 판정 하한 0.95pu와 다름 |
| 발전기 과도 리액턴스 설정 | `Xdp=1` | 고장 해석에 사용하는 모델 설정. 원본 인버터 시험값이나 검증된 기여 전류 배율은 아님 |
| 일반 선로 정전용량 | `C1=0`, `C0=0` | 정전용량 영향 무시 |
| 전압 판정 | `VOLTAGE_MIN_PU=0.95`, `VOLTAGE_MAX_PU=1.05` | 전압 영향: 범위 밖이면 이상 표시. 정전은 별도 처리 |
| 과부하 판정 | `OVERLOAD_PCT=100` | 부하율이 100%를 초과하면 과부하 |
| 역조류 판정 | 실제 전원→말단 방향과 P의 방향 비교 | 저장 방향이 정방향이면 P<0, 반대 방향이면 P>0 |
| 고장 종류 | `Solve mode=faultstudy` 후 `Bus.Isc()` 조회 | 3상 단락전류 크기 반환. 차단기 차단용량 비교는 없음 |

## 4. OpenDSS 결과와 최종 결과

| 시뮬레이션 | OpenDSS에서 읽는 값 | Python 처리·판정 | 결과 변수 / 단위 |
|---|---|---|---|
| 전압 영향 | `Bus.puVmagAngle()`의 첫 상 전압 크기 | 0.95~1.05pu와 비교 | `voltage_pu` / pu |
| 선로 과부하 | `CktElement.CurrentsMagAng()`의 첫 상 전류 크기 | 전류 ÷ 허용전류 × 100; 100% 초과 판정 | `loading_pct` / % |
| 역조류 | `CktElement.Powers()`의 첫 단자 3상 P·Q | 3상 P 합산 후 실제 전원 방향으로 부호 해석 | `p_kw`, `q_kvar`, `reverse_flow` |
| 단락 고장전류 | `Bus.Isc()`의 첫 상 복소전류 | 복소전류 크기 ÷ 1,000 | `fault_current_ka` / kA, 대칭 실효값 |
| 공통 상태 | `Solution.Converged()` 및 연결 탐색 | 수렴 실패 시 중단. 전원과 단절되면 정전 처리 | `converged`, `energized` |
| 부가 결과 | `Circuit.Losses()` 및 선로 P·Q | 손실 W→kW, 출구 차단기에서 나가는 선로 전력 합산 | `loss_kw`, 피더별 `p_kw`, `q_kvar` |

정전 노드는 `energized=False`, `voltage_pu=0`, `fault_current_ka=None`으로 반환한다. 입력 설비의 `p_kw`와 결과 선로의 `p_kw`는 이름이 같지만 각각 소비·발전량과 계산된 선로 전력을 뜻한다.

## 5. 원본에 있으나 미사용인 값과 화면 정보

| 항목 | 현재 처리 |
|---|---|
| 선로 `r0`, `x0` | 원본에는 있으나 현재 변환에서 전달하지 않음. 지락 해석 확장 시 검토 필요 |
| 태양광 `maxOperatingP`, `minOperatingP` | 원본에는 있으나 현재 출력 결정에 사용하지 않음 |
| 부하 `pfixed` | 원본 p와 같은 값이어서 미사용 |
| 단자 순번 | 연결 정리에는 읽지만 전원 방향을 보장하는 값으로 사용하지 않음 |
| 단선도 좌표 `x`, `y` | 자동 배치한 화면 좌표. OpenDSS 입력이 아니며 실제 선로 길이를 뜻하지 않음 |
| 피더·개폐기 연결선 | 연결 구조에서 자동 생성. 원본 선로 11개와 차단기 연결선 2개를 구분 |

웹에서 노드를 이동해도 실제 길이는 별도 속성으로 유지해야 한다. 일반 선로 임피던스는 `(R1+jX1)×length`로 구성한다. 원본 변환에서는 구간 r·x를 길이로 나눴다가 다시 곱하므로 원본 구간 임피던스가 보존된다. 이후 Ω/km 값을 유지한 채 길이를 편집하면 구간 임피던스가 바뀐다.
